# Roles and Permissions

## Activity Roles

Activity members can have different roles.

The main activity roles are:

- OWNER
- ADMIN
- MEMBER

## OWNER

The owner is the creator or primary owner of an activity.

Owner permissions are determined by the application's authorization rules.

## ADMIN

An activity administrator can perform administrative actions allowed by the activity's permission system.

## MEMBER

A member participates in an activity and completes its tasks.

Members generally do not have the same administrative permissions as owners or administrators.

## Global Roles

Users also have a global role.

The main global roles include:

- USER
- ADMIN

A global ADMIN has application-level administrative permissions according to the application's authorization rules.

## Important Rule

The chatbot must not invent permissions.

If a user asks whether they can perform a specific action, the chatbot should use the documented permission rules or available application data.
