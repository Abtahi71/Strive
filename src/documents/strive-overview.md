# Strive Overview

## What is Strive?

Strive is a productivity and habit-tracking application where users can create or join activities and complete tasks together.

Users can track their daily progress, task completion, streaks, achievements, and activity performance.

## Main Concepts

Strive is built around several concepts:

- Users
- Activities
- Activity members
- Tasks
- Task schedules
- Task progress
- Daily activity progress
- Streaks
- Achievements
- Invitations
- Friendships

## Activities

An Activity is a shared space where users participate in a collection of tasks.

An activity can have:

- A name
- A description
- An image
- A creator
- Multiple members
- Multiple tasks
- A visibility setting
- Daily progress information

## Tasks

Tasks belong to activities.

A task defines something that members should accomplish.

Tasks can have:

- A name
- A description
- A target value
- A unit
- A task type
- A schedule
- Progress records
- Achievements

## Progress

Users can record their progress toward tasks.

Strive tracks:

- Completed values
- Completion status
- Daily progress
- Current streak
- Longest streak
- Activity completion rate

## Achievements

Achievements provide additional goals associated with tasks.

A user can make progress toward achievements and eventually earn them.

## Social Features

Strive allows users to:

- Add friends
- Send and receive activity invitations
- Participate in activities
- Communicate through activity conversation groups
